# 📝 To-Do List App

A simple command-line To-Do List application built with Python that allows users to manage daily tasks efficiently.

## Features

- Add new tasks
- View all tasks
- Remove completed tasks
- Automatically saves tasks to a file
- Loads saved tasks when restarted

## Technologies Used

- Python 3
- File Handling
- Lists
- Functions
- Exception Handling

## Project Structure

```
todo-list/
│
├── todo.py
├── tasks.txt
├── README.md
├── requirements.txt
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/todo-list.git
```

Go to the project folder:

```bash
cd todo-list
```

Run the application:

```bash
python todo.py
```
